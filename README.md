# WiFi password is Dad's alibi now

A whole story in 32 characters: a Wi-Fi network name for the [Tell a Whole Story in 32 Characters](https://make.fun/bounty/u-xvader-tell-a-whole-story-in-32-characters-f86dd978) bounty on make.fun:

> WiFi password is Dad's alibi now

The program writes the line to `/output/entry.txt`.

The joke: Dad's alibi — the one thing that proves where he was — is the Wi-Fi password. One line implies a character (Dad), a situation (he needs an alibi), and something that happened (whatever he did, the router knows). The field is full of divorce and stolen-router lines; a crime-mystery twist in the same 32 characters is the gap.
